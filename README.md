# 中国节假日与传统节日日历

适用于 Apple Calendar / iPhone 的中国节假日订阅日历。

包含：

- 中国传统节日
- 法定节假日
- 调休补班日
- Apple 风格显示：
  - 正节日：`春节`
  - 额外休息日：`春节（休）`
  - 调休上班日：`春节（班）`

## 订阅地址

https://raw.githubusercontent.com/tarynwyj/2026china-holidays-workdays/main/china-holidays.ics

## iPhone 添加方法

设置 → App → 日历 → 日历账户 → 添加账户 → 其他 → 添加已订阅的日历

粘贴上面的订阅地址即可。

## 当前覆盖年份

- 2026：传统节日 + 官方放假调休
- 2027：传统节日
- 2027 官方放假调休安排公布后更新

## 数据说明

农历传统节日日期参考权威公历—农历对照资料。

法定节假日及调休安排以国务院办公厅正式通知为准。

本项目为个人维护的日历订阅文件，并非 Apple 或中国政府官方日历。
